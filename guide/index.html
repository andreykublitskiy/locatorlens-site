User guide

Open DevTools on the page you are testing → Elements → LocatorLens. The first-run walkthrough is also under ? in the pane.

Select an element

Click a node in Elements, or inspect with Ctrl+Shift+C (⌘+Shift+C on macOS). LocatorLens ranks locators for that one element.

Pick from page

On the Locators tab, turn on Pick from page, then move the mouse over the web page (not this pane). The list follows the cursor. Ordinary clicks still use the page. Hold Space and click to pin an element without activating it. Esc unpins.

Menus, dropdowns, and account popups

  1. Turn Pick from page on.
  2. Click the control that opens the menu (do not hold Space).
  3. Hover items inside the open menu. Hold Space and click to pin an item. The menu stays open; click a locator row later if you need it selected in Elements.

This also works when the menu is a widget iframe, such as Gmail’s account card. Hover inside the open card, not only the avatar. If the list stays on the opener, press Esc, then move onto the card.

Copy and verify

Copy takes the raw locator. As copies a snippet (Python, Playwright, Java, JavaScript, C#, Cypress). Playwright prefers getByRole, getByLabel, and getByTestId when those rows are Best. Verify checks a locator you type.

Library

This page lists saved locators that still match the document you are on. All saved keeps every locator, including other sites. Filter matches name, locator, project, or page as you type. Wrap a pattern in /slashes/ for a regular expression (/privacy/i, /^logout/); invalid patterns fall back to ordinary text.

Save this page expands collapsed nav sections and briefly opens account/help popups so items created on click are stored, then restores the page. Each control gets one unique test id, role, id, label, or name locator. You can still export after the trial or a subscription ends.

Settings

Theme is Light, Auto, or Dark. Auto follows DevTools (then the OS). Copy as sets the default language for As and Shift+Enter. The attribute list is the test-ID attributes your app uses, highest first.

Feedback

Account → Send feedback. Nothing about the page under test is attached.
